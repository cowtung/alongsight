# AlongSight

**AlongSight** is a music sight-reading tutor application built with JUCE and modern C++17. It provides real-time audio input analysis, visual feedback, and interactive sight-reading exercises.

## Features

- **Real-time Audio Input**: Captures audio from microphone or instrument input
- **Audio Level Meter**: Visual feedback of input audio levels with color-coded display
- **Music Staff Display**: Interactive musical notation display for sight-reading exercises
- **Start/Stop Controls**: Easy-to-use interface for controlling audio capture

## Technology Stack

- **Language**: C++17
- **Framework**: JUCE 7.0.9
- **Build System**: Projucer (JUCE's project management tool)
- **Platform**: Cross-platform (Windows, macOS, Linux)

## Prerequisites

- JUCE Framework (download from [juce.com](https://juce.com/get-juce/download))
- Projucer (included with JUCE)
- C++17 compatible compiler:
  - **Windows**: Visual Studio 2019 or later
  - **macOS**: Xcode (latest version recommended)
  - **Linux**: GCC 7+ or Clang 5+
- Platform-specific dependencies (see Building section)
- Audio input device (microphone or instrument interface)

## Coding Style

- **Indentation**: Tabs (displayed as 4 spaces)
- **Tab width**: 4 spaces
- **Format**: Use clang-format (config in `.clang-format`)

## Building the Project

### Quick Start

1. **Install JUCE**: Download and install JUCE from [juce.com](https://juce.com/get-juce/download)
2. **Open Project**: Open `alongsight.jucer` in Projucer
3. **Export**: Click "Save Project and Open in IDE" to generate native project files
4. **Build**: Build the project in your IDE

### Windows (Visual Studio)

```bash
# Clone the repository
git clone https://github.com/cowtung/alongsight.git
cd alongsight

# Open alongsight.jucer in Projucer
# Click "Save Project and Open in IDE" (Ctrl+P)
# This opens Visual Studio with the generated solution

# In Visual Studio:
# - Select Release or Debug configuration
# - Build > Build Solution (F7)
# - Run with F5 or Ctrl+F5

# Executable location:
# Builds\VisualStudio2026\x64\Debug\App\AlongSight_App.exe
```

### macOS (Xcode)

```bash
# Clone the repository
git clone https://github.com/cowtung/alongsight.git
cd alongsight

# Install Xcode from App Store if not already installed
xcode-select --install

# Open alongsight.jucer in Projucer
# Click "Save Project and Open in IDE"
# This opens the project in Xcode

# In Xcode:
# - Select your build scheme
# - Product > Build (⌘B)
# - Product > Run (⌘R)

# Application bundle:
# Builds/MacOSX/build/Debug/AlongSight_App.app
```

### Linux

```bash
# Install dependencies (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y build-essential git \
    libasound2-dev libjack-jackd2-dev \
    libfreetype6-dev libx11-dev libxrandr-dev \
    libxinerama-dev libxcursor-dev libwebkit2gtk-4.0-dev

# Clone the repository
git clone https://github.com/cowtung/alongsight.git
cd alongsight

# Open alongsight.jucer in Projucer
# Click "Save Project and Open in IDE" to export Makefile

# Build
cd Builds/LinuxMakefile
make CONFIG=Release

# Run
./build/AlongSight_App
```

## Usage

1. Launch the AlongSight application
2. Click the **Start** button to begin audio capture
3. Play your instrument or sing - the audio meter will show input levels
4. The staff display shows the musical notation area (exercise generation coming soon)
5. Click **Stop** to pause audio capture

For detailed setup and usage instructions, see [QUICKSTART.md](QUICKSTART.md).
